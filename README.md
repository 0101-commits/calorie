# ⚡ 프로틴레이더 (Protein Radar)

> 외식 프랜차이즈·편의점 메뉴의 단백질 가성비·영양 검증 및 개인 맞춤 추천 서비스  
> **기획서 기준:** 프로틴레이더 기획서 v1.1 (2026-09-15 확정 스펙)

---

## 📌 1. 서비스 개요 및 목적
편의점이나 외식 프랜차이즈 매장 앞에서 **3초 안에 "얼마나 싸게(PPR), 얼마나 가볍게(CPD), 얼마나 깨끗하게(NPI) 단백질을 얻는가"**를 검증하고, 나에게 꼭 맞는 1끼 단품 및 조합(콤보)을 추천하는 서비스입니다.

- **브랜드:** 프로틴레이더 (1~2단계) → 확장기 밀레이더 (3단계)
- **대상 채널:** 편의점 4사 (CU, GS25, 7-ELEVEN, 이마트24) + 외식 프랜차이즈 10개사 (써브웨이, 맥도날드, 버거킹, 맘스터치, 롯데리아, 샐러디, 한솥도시락, 본죽, 도미노피자, 파리바게뜨)
- **원칙:** 비회원제 (신체 정보는 기기 LocalStorage에만 저장), 광고 슬롯 제외, 72시간 정정 SLA 제공

## 🔬 2. 핵심 지표 체계 및 산식

### ① PPR (Protein-Price Ratio, g/천원) — 가성비 지표
$$\text{PPR} = \frac{\text{protein\_g}}{\text{price\_krw} / 1,000}$$
- **A등급:** $\ge 8.0$ (가성비 1등)
- **B등급:** $5.0 \sim 7.9$
- **C등급:** $3.0 \sim 4.9$
- **D등급:** $< 3.0$

### ② CPD (Calorie-Protein Density, g/100kcal) — 다이어트 밀도 지표
$$\text{CPD} = \frac{\text{protein\_g}}{\text{kcal} / 100}$$
- **A등급:** $\ge 12.0$ (다이어트 1등)
- **B등급:** $8.0 \sim 11.9$
- **C등급:** $5.5 \sim 7.9$ (식약처 법적 고단백 열량 기준)
- **D등급:** $< 5.5$

### ③ NPI (Net Protein Index, 보정 g) — 클린 식단 지수
$$\text{NPI} = \text{protein\_g} \times Q(\text{protein\_source}) \times (1 - \min(0.50, \sum \text{penalty})) + \text{bonus}$$
- **원물 품질 가중치 $Q$:**
  - $Q_1 = 1.00$: 닭가슴살, 원육, 계란, 생선살, 두부, 유청단백
  - $Q_2 = 0.90$: 분리대두단백(ISP), 콩, 치즈
  - $Q_3 = 0.80$: 성형육, 크래미, 어묵, TVP 대체육
  - $Q_4 = 0.70$: 햄, 소시지, 베이컨, 가공패티, 핫바
  - $Q_5 = 0.60$: 밀글루텐, 빵/면/곡류 또는 미분류
- **유해요소 페널티 (최대 -0.50 차감 한도):**
  - 튀김 조리: $-0.15$
  - 나트륨 1,000mg 이상 (1일 기준치 50% 초과): $-0.15$
  - 포화지방 10g 이상: $-0.15$
  - 당류 20g 이상 또는 당류 $\ge$ 단백질: $-0.10$
  - 트랜스지방 0.5g 이상: $-0.10$
  - 식이섬유 5g 이상 보너스: $+1.0\text{g}$
- **등급:** A ($\ge 25$), B ($18 \sim 24.9$), C ($12 \sim 17.9$), D ($< 12$)

### ④ 프로틴 워싱 판독 필터 (PW Score: 0~100)
단백질 마케팅 강조 표기(`marketing_claim = true`)가 된 제품을 대상으로 6개 정량 기준(W1~W6)을 평가:
- **0~24점:** 검증 고단백 (초록)
- **25~49점:** 조건부 (노랑, 벌크업 등 특정 목적에만 적합)
- **50~100점:** 프로틴 워싱 의심 🔴 (종합 등급 1단계 강등, 클린/다이어트 랭킹 제외, '이번 주 워싱 주의' 섹션 게시)

## 🎯 3. 개인 맞춤 추천 및 조합(콤보) 최적화
1. **BMR / TDEE 계산:** Mifflin-St Jeor 공식 적용
2. **운동 목적별 매크로:** 다이어트($\text{TDEE} \times 0.80$, 단백질 $2.0\text{g/kg}$), 린매스업($\text{TDEE} \times 1.08$, 단백질 $1.8\text{g/kg}$), 벌크업($\text{TDEE} \times 1.15$, 단백질 $1.6\text{g/kg}$)
3. **1끼 타깃 벡터 산출:** 끼니 비중(점심 35%, 저녁 30%, 아침 25%, 간식 10%)
4. **Fit Score (가중 정규화 거리):** 비대칭 방향 계수(단백질 초과는 감점 절반, 나트륨/당류 미달은 무감점) 적용
5. **편의점 1끼 조합 추천:** 상위 30개 단품 대상 2개~3개 조합($C(30,2) + C(30,3) \le 4,495$건) 실시간 생성, 예산/칼로리 제약 검증, Jaccard 유사도($\le 0.5$) 기반 다양성 5선 추천

## 🏗️ 4. 기술 스택 및 아키텍처 (B안 확정)

```
[클라이언트: GitHub Pages (정적 웹)]
  ├─ index.html (모바일 3탭 UI, SEED Design System 토큰 브리지)
  ├─ data.json (101건 검증 데이터 스냅샷, gzip 기준 < 300KB)
  ├─ js/score.js (지표 3종, 페널티, 워싱 판독 엔진)
  ├─ js/calc.js (BMR, TDEE, Fit Score, 개인화 추천)
  ├─ js/combo.js (편의점 1끼 2~3개 조합 최적화)
  ├─ js/search.js (초성 분해 ㄷㄱㅅㅅ 및 레벤슈타인 편집거리 검색)
  ├─ js/scan.js (BarcodeDetector API & ZXing 폴백 바코드 스캐너)
  └─ js/qa.js (R1~R5 정합성 검증 엔진)

[백엔드: Cloudflare Workers & D1 (SQLite)]
  ├─ schema.sql (D1 SQLite 8개 테이블 스키마)
  └─ worker/worker.js (/api/barcode, /api/report, /api/submit)

[데이터 파이프라인 & CI/CD: GitHub Actions]
  ├─ scripts/build.js (QA 검증 → 지표 산출 → data.json 정적 빌드)
  ├─ .github/workflows/test.yml (Node.js 단위 테스트 및 빌드 검증)
  └─ .github/workflows/deploy.yml (GitHub Pages 자동 배포)
```

## 🚀 5. 로컬 개발 및 실행 방법

### 1) 단위 테스트 실행
```bash
npm test
```
기획서 §1.7에 명시된 6건의 벤치마크 예시(훈제 닭가슴살, 샐러드, 프로틴 초코 음료, 워싱 김밥, 치킨버거 세트, 삼각김밥)와 BMR, TDEE, 초성 검색, QA 룰셋이 모두 100% 통과합니다.

```bash
npm run build
```

```bash
npm run serve
# 브라우저에서 http://localhost:8080 접속
```

## 🛡️ 6. 법무 및 신뢰 장치
- **면책조항:** 본 서비스는 정보 제공 목적이며 의학적 조언을 대신하지 않습니다.
- **72시간 정정 SLA:** 각 카드의 "이 숫자 틀렸어요" 버튼을 통해 접수된 오류는 72시간 이내에 공식 영양표를 재확인하여 반영합니다.
- **비회원제:** 사용자 신체 정보는 서버에 전송되지 않으며 브라우저에만 보관됩니다.
